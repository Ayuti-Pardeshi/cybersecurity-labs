
# Basic Linux Commands

## Overview
- **Subject:** Linux Administration
- **Lab:** Basic Linux Commands
- **Environment:** [Kali Linux / Ubuntu / other]
- **Topics:** Directory navigation, file management,
  text processing, searching, and command-line utilities.

## Objectives
- Navigate the Linux filesystem.
- Create and manage files and directories.
- View, search, and count text-file contents.
- Understand absolute and relative paths.

## Part A — Directory Navigation

### 1. Display the current working directory

**Command**
```bash
pwd
```

**Learning:** `pwd` prints the current working directory.

### 2. List directory contents

**Command**
```bash
ls
```

**Learning:** `ls` lists directory entries.
